Kompetensi Inti Administrasi Server

Teknik Komputer dan Jaringan membekali siswa dengan kemampuan membangun, mengonfigurasi, dan memelihara layanan jaringan menggunakan sistem operasi Linux Server.

Berbeda dari penggunaan desktop biasa, pengelolaan Linux Server melatih ketelitian dalam konfigurasi alamat IP statis, manajemen daemon lewat systemctl, serta akses jarak jauh melalui SSH.

01

Efisiensi Sumber Daya

Berjalan optimal pada mode teks (CLI) sehingga RAM dan CPU fokus melayani permintaan perangkat client.

02

Layanan Jaringan Terpadu

Satu server dapat menjalankan Web Server, DNS Server, DHCP Server, File Server, dan Firewall secara bersamaan.

03

Administrasi Jarak Jauh

Mengelola konfigurasi server secara aman dari komputer administrator menggunakan protokol SSH.

04

Standar Industri & Virtualisasi

Siap diimplementasikan pada lingkungan VirtualBox maupun infrastruktur server produksi berbasis Debian/Ubuntu.

01

Pengertian Linux Server

Linux Server adalah versi sistem operasi Linux yang dikonfigurasi dan dioptimalkan untuk berjalan di komputer server guna melayani permintaan dari perangkat lain (client) melalui jaringan komputer maupun internet.

Umumnya Linux Server dioperasikan lewat CLI (Command Line Interface) atau akses jarak jauh seperti SSH agar lebih ringan, hemat sumber daya, dan stabil.

02

Perbedaan Linux Server & Desktop

  • Antarmuka: Linux Server fokus pada mode teks (terminal/CLI) tanpa membebani memori dengan tampilan desktop berat; Linux Desktop memakai GUI untuk kebutuhan harian.
  • Kestabilan & Uptime: Linux Server dirancang menyala terus-menerus (24/7) dengan efisiensi CPU dan RAM maksimal.
  • Keamanan: Layanan dan port pada Linux Server dibatasi hanya pada kebutuhan tertentu agar lebih aman.
03

Fungsi & Layanan Umum pada Linux Server

Satu mesin Linux Server dapat menjalankan berbagai layanan jaringan sesuai kebutuhan:

Web Server

Menyajikan situs dan aplikasi web menggunakan perangkat lunak seperti Apache atau Nginx.

DNS Server

Menerjemahkan nama domain ke alamat IP (misalnya menggunakan BIND9).

DHCP Server

Membagikan IP Address, Subnet Mask, Gateway, dan DNS secara otomatis kepada client.

File Server

Berbagi file atau penyimpanan terpusat dalam jaringan seperti Samba atau NFS.

Firewall & Routing

Mengatur lalu lintas paket data dan keamanan jaringan antar segmen.

04

Distro Populer untuk Linux Server

Debian Server

Dikenal sangat stabil, ringan, dan menjadi rujukan utama dalam pembelajaran Teknik Komputer dan Jaringan maupun server produksi.

Ubuntu Server

Memiliki dukungan dokumentasi dan paket perangkat lunak yang luas serta jadwal rilis LTS (Long Term Support) yang jelas.

Rocky Linux / AlmaLinux

Alternatif enterprise yang kompatibel dengan ekosistem Red Hat / CentOS di lingkungan perusahaan.

05

Perintah Dasar Administrasi Linux Server

Selain perintah dasar Linux (pwd, ls, cd, sudo, ip a, ping), administrator Linux Server sering menggunakan perintah berikut:

Perintah Fungsi
ssh user@ip_serverMengakses Linux Server dari jarak jauh melalui jaringan
systemctl status <layanan>Mengecek status layanan (seperti apache2, nginx, atau ssh)
systemctl restart <layanan>Memuat ulang layanan setelah mengubah konfigurasi
ip aMelihat konfigurasi alamat IP interface server
ping <tujuan>Menguji konektivitas jaringan antara server dan client
06

Alur Belajar Linux Server untuk Teknik Komputer dan Jaringan

Langkah 1 Menyiapkan mesin virtual di VirtualBox menggunakan ISO Linux Server (misalnya Debian atau Ubuntu Server).
Langkah 2 Mengatur adaptor jaringan dan mengonfigurasi IP Address statis agar server mudah diakses.
Langkah 3 Berlatih mengelola file, hak akses, dan layanan lewat terminal / SSH.
Langkah 4 Membangun layanan inti satu per satu seperti Web Server, DNS Server, dan DHCP Server.
